From observation to intervention

A controller reads training measurements and submits changes through a control interface. The training process applies those requests while the run continues. Optimizer settings, data handling, and checkpoints become part of an interactive feedback loop.

Interactive Training 2 makes this interface a shared protocol. A training application declares typed settings and actions, applies requests at its control points, and records requests and outcomes in an ordered journal. Humans, scripts, and language-model agents use the same interface.
